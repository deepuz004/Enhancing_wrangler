Great question! ANTLR is at the heart of this assignment — understanding it will help you modify the grammar correctly.

🔍 What is ANTLR?
ANTLR stands for ANother Tool for Language Recognition.
It's a powerful tool used to create parsers — programs that can understand and process structured text or code.

In simpler terms:
ANTLR reads a grammar file (like Directives.g4) and generates Java classes that can:

Recognize patterns (like 10MB, 1.5s)

Break down input into parts

Help Java code understand and act on those parts

🧠 Why Is It Used in Wrangler?
In CDAP Wrangler, users write recipes with steps like:

ruby
Copy
Edit
parse-as-csv :body , true
drop :header
aggregate-stats :size :duration total_size total_time
ANTLR is used to parse and understand these recipes:

What is a directive?

What are its arguments?

What kind of data is that (e.g., string, number, new types like BYTE_SIZE)?

📄 ANTLR Grammar File: Directives.g4
This is where you define:

What counts as a valid directive

What a BYTE_SIZE or TIME_DURATION token looks like

How the parser should interpret them

Later, when you run mvn compile, ANTLR will generate Java code based on that .g4 grammar file.

🧩 Example:
Suppose your grammar includes:

antlr
Copy
Edit
BYTE_SIZE
  : DIGIT+ ('.' DIGIT+)? ('KB' | 'MB' | 'GB' | 'TB')
  ;
ANTLR will generate code that knows:

10MB is a BYTE_SIZE token

You can now act on that token in Java (e.g., convert it to 10485760 bytes)
